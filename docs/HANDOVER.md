## 今の状態

- デジタルシングルCD『HAMMOCK AT LOW TIDE』(NK-S004)。PWA テンプレート構成(Vite + TypeScript + vite-plugin-pwa)。公開は GitHub Actions → GitHub Pages(リポジトリ `tanabata-soft/034lw21ypp`)、URL は https://tanabata-soft.github.io/034lw21ypp/ 。
- エンジンはデジタルCDアルバム(NK-001)・デジタルシングルCD(NK-S001〜NK-S003)と共通。作品データは `src/album/` に集約され、エンジンはそこだけを参照する。NK-S003 のリポジトリをコピーして制作した。
- 収録: 全2曲・総再生時間 5:25。1. HAMMOCK AT LOW TIDE(2:50、表題曲)／2. BENEATH THE SILVER GLINT(2:35、カップリング)。ボーナストラックなし(形式の原則どおり)。
- **初の全曲インストゥルメンタル盤**: 歌詞データは持たない。`sync.ts` は各曲キーに空配列を置く形にし、単体テスト(tests/data.test.ts の歌詞長のアサーション)と内容検査(scripts/content-checks.mjs の sync-keys が `"key": []` もキーとして数える)をインスト盤に合わせて調整した。プレイヤー側は `SYNC[src] ?? []` で無歌詞を許容し、再生画面に歌詞行は出ない(e2e で 0 行を assert 済み)。
- 音源はオーナー提供の MP4(Gemini 生成動画)から音声のみを切り出した音声だけの MP4。track01 は末尾のフェードアウト完了点 170.0 秒でトリムし、Gemini ロゴのアウトロ(無音)を取り除いた。track02 は末尾の無音を詰めて 155.0 秒。
- **シングル形態の分岐**: `album.ts` の `layout: 'single'` で、8cmシングル短冊型ジャケット(1:1.938)、ブックレットなしを切り替える。裏面は2曲のジャケット結合画像(back.jpg)の上にライナーノート・曲目(番号・タイトル・ジャンル・長さ、**表示専用**)・バージョン表示を載せるパネル。**back.jpg**: 上=表題曲ジャケット(枠なし、全面が絵)、下=カップリングジャケット(白枠を実測 36px @720 で除き内側の絵だけ)、継ぎ目は約90pxのクロスフェードでなじませた(制作ルールは docs/PRODUCTION.md の注意)。再生画面の曲ジャケット(trackNN.jpg)は元のまま。トップのボタンは再生のみ。再生画面の右端ボタンはリピート切替(全曲⇔1曲)。トップへ戻ると再生停止。
- Service Worker は vite-plugin-pwa の自動生成。「更新」ボタン方式。音源は初回起動時に一括ダウンロード(表示つき、キャッシュ名 `hammock-single-audio`)、画像は事前キャッシュ。
- 背景(bg.jpg)はテーマ色(夕海のスレート)の色面グラデーション。テーマ色は #14232e。

## 注意・気づいたこと

- **仮置き(オーナー確認待ち)**: ジャンル表記(1=Seaside Bossa、2=Night Ambient)とライナーノーツ・曲解説は、音の分析値(テンポ・音量推移)とジャケット絵からの推定で書いた。制作者(Muse)には耳がないため、実際の音の印象と違う場合は差し替える。両曲がインストであることも文字起こしの結果からの判断で、オーナーの「多分インスト」が前提。声の入った箇所があれば歌詞収録に切り替える。
- 表ジャケットは実物の8cmシングル(短冊)の様式調査(docs/SINGLE-DESIGN-STUDY.md)の**型B(1992–95: タイポグラフィ勝負)**で、オーナーが候補3案(A/B/C)から選択した(2026-11-05)。絵は新規生成のミニマルな海景写真(干潮の浜辺と小さなハンモック)、タイトル文字は生成後に合成。折り目の演出はない(オーナー指示)。アプリアイコンはジャケット上部のタイトルブロックを正方形に切り出して作成(scripts/make-icons.mjs の手順コメント参照)。差し替える場合は 1200×2326(1:1.938)で jacket.jpg を置き換え、アイコンも作り直す。
- 曲ジャケットの原画解像度は track01 が 1024×1024、track02 が 720×720(提供 MP4 のフレーム抽出)。
- Netlify は使わない(サウンド単行本の納品枠を温存する決まり)。公開は GitHub Pages のみ。
